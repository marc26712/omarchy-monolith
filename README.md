# monolith

Thème omaLauncher / Omarchy — 2001 : L'Odyssée de l'espace

Le monolithe noir et Jupiter. Arête éclairée en lumière rasante, noir profond, ivoire. Sobre et froid.

## Install

Settings → Theme → coller l'URL du dépôt :

    github.com/marc26712/omarchy-monolith

## Contenu

- `colors.toml` — palette (dark)
- `backgrounds/` — 3 fonds 1080×2400 (9:20)

## Crédits images

Jupiter : NASA/JPL/Cassini (domaine public). Compositions et monolithe : rendu interne.
